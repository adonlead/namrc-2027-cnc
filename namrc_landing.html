NAMRC 2027 · NASA Milling Research Platform

An AI-Enabled Web-Based Framework for CNC Tool Wear Prediction and Interactive Manufacturing Simulation Using NASA Milling Data

An accessible research demonstration integrating machining-data exploration, case-grouped model validation, and browser-based tool wear estimation.

Research overview

This platform analyzes the publicly available NASA Milling dataset to study relationships between machining conditions, full-run sensor measurements, and recorded flank wear (VB). It combines an exploratory comparison of regression models with interactive examination of historical experiments and portable Ridge Regression inference. All modules use the same published data pipeline; no physical CNC machine is required to explore the recorded experiments.

Methodology and research scope

Data and evaluation

  • NASA Milling experimental records with recorded machining parameters and sensor signals.
  • Run-level sensor summaries and observed flank wear, where labeled.
  • Exploratory five-fold case-grouped cross-validation to reduce within-case leakage.
  • Ridge Regression selected from the evaluated models for the deployable inference demonstration.

Reproducible implementation

  • Automated dataset processing and model export through the research repository.
  • Published JSON endpoints supply records, validation results, and fitted model parameters.
  • Browser inference reproduces the exported Python model formula.
  • Original NASA observations are distinguished from fitted estimates and hypothetical input combinations.
Research limitations. The fitted model uses statistics computed from completed machining runs; this is not real-time tool monitoring or validated early-warning forecasting. Editing inputs produces a model-based estimate, not a verified counterfactual machining outcome. Thresholds are exploratory, and the source units of VB and the treatment of the flagged anomalous record require final documentation checks. No tool-replacement or safety recommendation is implied.
